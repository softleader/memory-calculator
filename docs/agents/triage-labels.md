# Triage Labels

| Canonical role | GitHub label | 意義 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待維護者評估 |
| needs-info | needs-info | 等待回報者補充資訊 |
| ready-for-agent | ready-for-agent | 規格與驗收條件完整，可由 agent 自主執行 |
| ready-for-human | ready-for-human | 需要人員實作 |
| wontfix | wontfix | 不予處理 |

Skills 提及 triage role 時，使用表中的 GitHub label。

`ready-for-agent` 表示工作本身已具備自主執行條件；
啟動 agent 是獨立的派工決定，不能僅由此標籤推定授權。
